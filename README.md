What is it? 
This  Python project, titled "Horror Game", is an interactive game where the character is moved by the user, using the keyboard letters, "w, a, s, d."
There is a "monster" who is after the character as well. 

How to play:
It's pretty simple. All you have to do, is put all these files in a platform called PixelPad. There, you press run, and you are able to move the 
character around the map. You have limits to how far you can go out of the map as well. Once you spawn into the game, another character also spawns. 
This is the monster, who is trying to catch you. Once the game starts, there are also keys that spawns at random locations, scattered around the map. 
Your job is to collide with all of the keys, keeping them in your inventory and once you collected all, you can collide with the door to finish the game. 
The monster will keep following you everywhere, and if it collides with you, you loose a heart. You have totally 3 lives to finish this game.
